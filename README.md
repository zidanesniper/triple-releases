# TRIPLE MODEL FINDER for Windows

Official customer installers from TRIPLE DESIGN STUDIO.

[Download TRIPLE MODEL FINDER for Windows](https://bytriple.com/download/windows)

## Install or update

1. Download the latest Windows installer using the link above.
2. Finish active downloads or indexing, then quit TRIPLE from its tray icon.
3. Run the installer and reopen TRIPLE. Complete activation if requested.

In TRIPLE, open **Settings → About & legal → Check for updates**, then follow the in-app download and installation prompts.

## Verify the download

Each release includes a `.sha256.txt` checksum. Use PowerShell `Get-FileHash -Algorithm SHA256` on the downloaded installer and compare it with that file. The current installer is not digitally signed.
